Set the teacher code

Choose a code that teachers type to host a live game. Use a long phrase (12 or more characters), not a short word. This page works entirely in your browser; the code you type is never sent anywhere or saved.

Open supabase-config.json on GitHub, click the pencil icon, replace everything with the text below (keeping your url and anonKey as they are), and commit. The game updates within a couple of minutes. Only a scrambled version of your code is stored, never the code itself.
